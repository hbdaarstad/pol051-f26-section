Box plots

🚨 Your turn: 🏒 Goals Box Plot 🏒 🚨

Using the hockey dataset:

  1. Build a box plot of the number of goals scored by all NHL players in the 2023–24 regular season.

  2. Color the outliers and change their shape.

  3. Add a point for the mean number of goals.

  4. Add a title, subtitle, and axis labels.

Tip

  1. Use aes(x = "", y = goals) to get a single box

  2. Outliers are set inside geom_boxplot() with outlier.color =, outlier.shape =, outlier.size =

  3. To add the mean: stat_summary(fun = mean, geom = "point")

🚨 🏒 Goals Box Plot Answer 🏒 🚨

ggplot(data = hockey, aes(y = "", x = goals)) +
  geom_boxplot(
    alpha = 0.7,                       # transparency of the box fill
    outlier.color = "cornflowerblue",  # color of outlier points
    outlier.shape = 8,                 # outlier symbol is a star
    outlier.size = 1                   # outlier size
  ) +
  stat_summary(fun = mean, geom = "point",
               shape = 20, size = 4, color = "coral") +
  labs(title = "Distribution of Regular Season Goals by Player",
       subtitle = "NHL 2023–24",
       x = "",
       y = "Goals Scored") +
  theme_minimal() +
  theme(legend.position = "none")

The mean sits above the median: a few big scorers pull the mean up (right-skewed)

Creating a new variable

🚨 Your turn: 🏒 Playoff Teams 🏒 🚨

Using hockey_boxplot and the playoffs_2024 list:

  1. Make a new variable called playoffs that is "Clinched" if the team made the playoffs and "Eliminated" if it did not.

  2. Store it as a new object called hockey_newvar.

Tip

  1. case_when() goes inside mutate()

  2. %in% checks whether a value is in a list: team %in% playoffs_2024

  3. There is no !%in%. For “not in”, use !(team %in% playoffs_2024)

🚨 🏒 Playoff Teams Answer 🏒 🚨

hockey_newvar <- hockey_boxplot |>
  mutate(playoffs = case_when(
    team %in% playoffs_2024 ~ "Clinched",
    !(team %in% playoffs_2024) ~ "Eliminated"
  ))

t-tests

🚨 Your turn: 🏒 t-test 🏒 🚨

Using hockey_newvar:

  1. Test whether teams that made the playoffs scored more total goals (Total) than teams that did not.

  2. Make a new variable offense_perct: the percent of goals from forwards (right wing + left wing + center).

  3. Test whether playoff teams get a different percent of their goals from defense (d_percent).

  4. Which differences are statistically significant?

Tip

  1. The formula is t.test(OUTCOME ~ GROUP, data = DATA)

  2. A difference is statistically significant if the p-value is less than 0.05

🚨 🏒 t-test Code Answer 🏒 🚨

t.test(Total ~ playoffs, data = hockey_newvar)

hockey_ttest <- hockey_newvar |>
  mutate(offense_perct = rw_percent + lw_percent + c_percent)

t.test(d_percent ~ playoffs, data = hockey_ttest)
